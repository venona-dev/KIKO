# KIKO

Минималистичный веб-мессенджер: общая стена, лайки и личные сообщения в реальном времени.

## Стек
- Node.js + Express
- PostgreSQL
- Socket.IO
- Обычный HTML/CSS/JS frontend

## Локальный запуск
1. Установите Node.js 20+ и PostgreSQL.
2. Создайте базу данных `kiko`.
3. Скопируйте `.env.example` в `.env` и укажите `DATABASE_URL` и длинный случайный `JWT_SECRET`.
4. Выполните `npm install`, затем `npm start`.
5. Откройте http://localhost:3000.

Таблицы создаются автоматически при старте.

## Развёртывание на Render
В репозитории есть `render.yaml` (Blueprint), который описывает веб-сервис и PostgreSQL. В Render выберите **New → Blueprint**, подключите этот GitHub-репозиторий и подтвердите создание ресурсов. После этого включите Auto-Deploy для ветки `main` в настройках сервиса.

## Безопасность
Пароли хешируются bcrypt. API и Socket.IO используют подписанные JWT. Для продакшена задайте уникальный секрет через переменную окружения; не храните секреты в репозитории.
